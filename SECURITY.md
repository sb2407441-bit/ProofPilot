# Security notes

- No API keys are included or needed for the default workflow. `.env` files, dependencies, build output and local logs are excluded from Git.
- Source desk makes an explicit external GET only after the user requests a public page. It accepts HTTPS DNS hostnames, rejects credentials/query/fragment/custom ports, checks every DNS answer and redirect against public-address restrictions, and pins the approved answer for the TLS request. No cookies, profile, authorization header or referrer are sent. TLS verification remains enabled. This is a local single-user feature, not a hardened public proxy; do not expose the server publicly.
- Source reads have a total 12-second network/decode timeout, at most three redirects, 512,000 wire bytes, 1,000,000 decompressed bytes and one concurrent capture. HTML parsing is inert; no page scripts, styles, linked pages or assets are loaded. At most 3,000 candidate blocks are scanned and 24 prioritized matches returned, with per-excerpt truncation labels. Keyword omission and contact detection are incomplete heuristics. Public URLs can still contain personal data in paths; use only non-sensitive public sources.
- Source results stay in memory; responses use `no-store`. Copied briefs contain the selected page text, source URL, capture time and digest. Review permission/privacy before sharing. Page text is untrusted and is rendered as escaped text, never executed or sent to an AI model. Source desk does not update curated evidence or invoke drafting.
- HTTP servers listen only on `127.0.0.1`. Host/origin checks reject unrelated origins. Provider connections accept HTTP loopback origins only, reject URL credentials and do not follow redirects.
- Request size and profile field lengths/types are bounded. Model output is parsed as a plan, then checked against known fact identifiers; model-written prose is never rendered as a factual draft.
- Sensitive-text checks block common key, private-key, identifier and email patterns before draft preparation or export. They are heuristics, not a complete confidentiality guarantee. Do not enter credentials, identity documents or employer data.
- No profile persistence, analytics, document uploads or application submission are implemented. Downloaded briefs are user-controlled files and may contain self-reported information.
- The offline comparison CLI bounds UTF-8 file reads, rejects nonregular/symlink input, emits fixed failure diagnostics and excludes profile fields from allowlisted reports. Reports still contain supplied evidence. Use synthetic/non-sensitive public inputs and review reports before sharing; do not put real profiles or private evidence in public CI logs or repositories.
- Snapshot and CLI profile JSON reject repeated object field names before schema evaluation, including escape-equivalent names. A 32-level nesting cap prevents subsequent recursive schema/privacy walks on excessively nested input. Fixed diagnostics include positions, never supplied field names or values. This does not detect a semantically incorrect single value or guarantee confidentiality.
- JUnit mode selects only fixed gate messages, policy, clock, profile mode and aggregate counts. Evidence values, URLs, individual decisions and profile values are omitted rather than redacted. Aggregate metadata still reveals a comparison/review; invalid comparisons produce no XML. This does not authorize private input use or automatic artifact publication.
- An optional local gateway can forward requests remotely. Inspect its own configuration and costs separately. This app sends only generic labels and identifiers to its model endpoint.
- The prototype has no authentication and is intended for one user on their own computer. Do not change the binding to a public network address without a separate security review.

Before sharing a repository, scan both the tracked tree and Git history and review the files yourself. A clean scanner result cannot prove the absence of every secret.
